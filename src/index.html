Projects

MyTide

MyTide is a Vue.js web app that provides real-time tide and weather information based on user location. It fetches data from an API to display daily high and low tides in an intuitive, mobile-friendly interface.

Built with Vue 3 and styled with Bootstrap, the app includes unit conversions, responsive design, and a location-based feature to enhance user experience.

MyTide is deployed on Netlify and serves as a practical tool for beachgoers, boaters, and coastal enthusiasts.
